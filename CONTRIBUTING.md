## How Can I Contribute?

### Reporting Vulnerabilities or Bugs
- If you find an error in the setup steps or an outdated tool version, please open a GitHub Issue.
- Provide a clear title, description of the problem, and steps to reproduce or verify the issue.
- **Critical Security Disclosures:** If you identify a critical bypass or active security vulnerability, please do not disclose it publicly in an open issue. Instead, open a security advisory or contact the maintainers directly.

### Suggesting Security Tools & Enhancements
- Propose new open-source security tools (e.g., Linux sandbox tools, firewall rules, network analyzers).
- Ensure the proposed tool is **open-source, actively maintained, and verified** against false positives.

### Improving Documentation (Bangla / English)
- Fix typos, broken URLs, formatting inconsistencies, or markdown layout bugs.
- Synchronize content updates across both the **Bangla** and **English** sections to keep the guide aligned.
